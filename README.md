# SIEM and SOAR with Microsoft Sentinel — A Practical Guide for SMBs
Last updated: 01/10/2026

Part of the **Microsoft 365 Security Foundations** series — practical, production-tested guides for securing Microsoft 365 as a small or growing business.

A guide to standing up Microsoft Sentinel as a small business's first SIEM/SOAR platform — connecting the signals from Entra ID, Intune, and Defender into one place and building the first detections and automated responses on top of them.
